2) Security Audit Report

Critical Findings

  • Stack trace leakage: malformed JSON returned internal stack trace in API response body (information disclosure risk).
  • Rate-limit key isolation bug: Redis limiter uses req.apiKey?.key, but model persists hashed key fields. Can collapse distinct tenants into shared limiter key path.

High/Medium Findings

  • Legacy QA scripts are out of sync with current auth verification flow, reducing reliability of security regression detection.
  • Global limiter behavior can hide true auth behavior during incident/load conditions due blanket 429 responses.

Positive Controls Observed

  • JWT auth middleware in place with explicit 401 on invalid/missing token paths.
  • API key middleware, permission checks, helmet, and mongo sanitization present.
